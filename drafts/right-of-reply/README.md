# Right-of-reply drafts

Drafts for inviting a response to an adverse item (a court or criminal matter, scandal, or allegation) live in this folder.

**The bot never sends these drafts.** The owner sends them personally, after a reviewer PASS and an owner GO on the exact text. Status on a profile stays `pending` until the owner records that a message was sent, that a reply was received, or that there was no response after the deadline.

Use `TEMPLATE.md` for a new draft. Do not put ID numbers, home addresses, personal phone numbers or personal emails in a draft.
