# Joburg LGE 2026 roster

`joburg-2026.csv` is the TEST-environment roster of City of Johannesburg councillors declared elected in Government Gazette 55741 (13 November 2026). Councillors are public office-holders named in a public gazette, so this file is committed. It contains public-role fields only: name as gazetted, party, seat type, ward number, and a source URL plus gazette page number for every row.

Columns `positions`, `education`, `career`, `court_matters`, and `scandals` are empty placeholders (treated as Unknown / none recorded). Curriculum vitae research has not started. There are no adverse items in this file, so no right-of-reply objects appear on these rows.

`joburg-2026-council.json` records council-level facts, including that the executive mayor is **Unknown** (expected around 19 November 2026) and that the council is hung (Confirmed, from the IEC seat calculation).

Quality notes and the primary-source URLs are in `docs/sources-joburg-lge-2026.md`.
